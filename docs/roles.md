# 成员身份与后台权限

| 身份 | 数据库 `role` | 来源 | 后台访问 | 修改成员身份 |
| --- | --- | --- | --- | --- |
| 会员 | `member` | 公开注册默认身份 | 否 | 否 |
| 普通成员 | `user` | 系统管理员指定 | 是 | 否 |
| 核心成员 | `core` | 系统管理员指定 | 是 | 否 |
| 系统管理员 | `admin` | 初始化账号或系统管理员指定 | 是 | 是 |

所有具有后台访问权限的身份都可使用现有活动、任务、记录和成员列表功能。只有系统管理员可在成员列表修改身份；普通成员和核心成员只能查看。系统管理员不能取消自己的管理员身份，以免失去后台身份管理权限。

注册接口不会接受身份字段。修改身份由服务端检查当前用户的 `admin` 身份，不依赖前端下拉框是否可见；权限变更在目标用户下一次请求时生效。个人空间的后台入口对 `user`、`core` 和 `admin` 可见。
